RSA Key Generator (C Engine)

⚠ Educational Demonstration Only: This module uses small numbers to illuminate the underlying mathematical steps. Real-world financial cryptographic systems (like online banking and HTTPS) utilize 2048-bit or 4096-bit primes (over 600 digits) to render brute-force integer factorization impossible.

Step-by-Step RSA Cryptographic Pipeline

Trace the exact number-theoretic transformations computed by WebAssembly.

Step 1 • Modulus Calculation Arithmetic Multiplication

Calculate the RSA modulus n as the product of primes p and q:

n = p × q = 61 × 53 = 3,233
Step 2 • Euler's Totient Function φ(n) Coprime Count

Count the number of positive integers less than n coprime to n:

φ(n) = (p - 1) × (q - 1) = 60 × 52 = 3,120
Step 3 • Key Pair Generation Extended Euclidean Algorithm

Public exponent e is chosen coprime to φ(n). Private key d is the modular multiplicative inverse:

(e × d) ≡ 1 (mod φ(n)) → (17 × 2753) mod 3120 = 1
🔓 Public Key (e, n)
(17, 3233)
Shared openly for encryption
🔒 Private Key (d, n)
(2753, 3233)
Kept secret for decryption
Step 4 • Encryption & Decryption Modular Exponentiation
Encryption (Locking message):
C = Me mod n = 6517 mod 3233 = 2,790
Decryption (Unlocking ciphertext):
M' = Cd mod n = 27902753 mod 3233 = 65
✅
Mathematical Proof Verified: Decrypted plaintext matches the original input message exactly (M' = M).

Number Theory

5. Prime Numbers & Factorization

Primes are integers greater than 1 with no positive divisors other than 1 and themselves. Multiplying two large primes is trivial, but factoring their product back into primes is computationally infeasible.

n = p × q   (p, q ∈ Primes)
Applied in RSA Key Gen →
Algorithms

6. Greatest Common Divisor (GCD)

The Euclidean algorithm computes the greatest common divisor of two integers via iterative modular remainder steps in logarithmic time O(log(min(a, b))). Essential for verifying coprimality.

gcd(a, b) = gcd(b, a mod b)
Applied in RSA Key Gen →
Number Theory

7. Euler's Totient Function φ(n)

Euler's totient function φ(n) counts positive integers up to n that are coprime to n. For the product of two distinct primes p and q, the multiplicative property yields an exact closed form.

φ(p · q) = (p - 1) × (q - 1)
Applied in RSA Totient Step →
Algebra

8. Modular Arithmetic

Often termed "clock arithmetic", numbers wrap around upon reaching a modulus n. It creates cyclic mathematical finite fields (&Z;/n&Z;) that preserve algebraic consistency under addition and multiplication.

a ≡ b (mod n) ⇔ n | (a - b)
Applied in Key Inversion →
Cryptography

9. RSA Asymmetric Encryption

Governed by Euler's Totient Theorem: Med ≡ M (mod n). Because only the private key holder knows d, anyone can encrypt with e, but only the intended recipient can invert the trapdoor permutation.

C = Me mod n,   M = Cd mod n
